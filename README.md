# OfferRoast

Status: **idea stage, nothing built yet.** The concept below is an assumption and must be confirmed before any code is written.

> Paste a job offer, get a blunt, funny-but-useful critique: red flags, what is missing, and what to ask for.
> The analysis is meant to run in your browser, so the offer never leaves your machine.

See `CLAUDE.md` for the working brief, lessons from the previous project and ground rules.

## Next steps

1. Confirm the concept, audience and tone.
2. Decide the smallest demo that a real person can react to.
3. Run a quick human test before building a full product (set kill criteria first).
